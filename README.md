# retroshelf Linux releases

Official Linux tracker releases for [retroshelf](https://retroshelf.org).

## NextUI Pak

The retroshelf pak reads completed sessions from NextUI's native activity database and syncs them to your retroshelf account.

To install it, download the versioned `retroshelf-nextui-v*.zip` release asset and copy its `retroshelf.pak` folder into `Tools/tg5040` or `Tools/tg5050` on the SD card.

This repository also publishes synchronized tracker packages for OnionOS, muOS, SpruceOS, Knulli, Batocera, SteamOS, and ROCKNIX. Release assets are built from the [retroshelf source repository](https://github.com/ruigomeseu/retroshelf).
